# Security policy

## Reporting a vulnerability

If you believe you have found a security issue in Anchor, please report it privately via GitHub Security Advisories:

**<https://github.com/Hans-Tandt/Anchor/security/advisories/new>**

Please do **not** open a public GitHub issue for security matters.

## What to include

- A short description of the issue.
- Steps to reproduce.
- The impact you think it could have.
- Your suggested fix, if any (optional).

## What to expect

- I aim to acknowledge new reports within **7 days**.
- I will keep you updated on progress until the issue is resolved or closed as won't-fix.
- When a fix ships, I will credit you in the release notes (unless you prefer to stay anonymous).

## Supported versions

Only the latest release on the [Releases page](https://github.com/Hans-Tandt/Anchor/releases/latest) is supported. Older versions may receive fixes at my discretion.
